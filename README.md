# Proyecto Lucía

Lucía is a local-first personal AI system designed as an autonomous, persistent software presence rather than a conventional chatbot.

## Vision

Lucía will integrate:

- dynamic context
- selective long-term memory
- learning from experience
- perception of the computer environment
- model routing across local LLMs
- tools and controlled actions
- voice and visual presence
- curiosity and selective initiative

The project is inspired by cognitive science and neuroscience where those principles can be translated into useful, testable computational mechanisms.

## Core principles

1. Lucía is a system, not a single LLM.
2. Context and long-term memory are separate mechanisms.
3. Memory is selective rather than an unlimited conversation log.
4. Learning should change future behavior, not merely accumulate text.
5. Perception should be filtered through salience before reaching expensive reasoning models.
6. Local models are interchangeable cognitive engines behind a persistent Lucía identity.
7. Autonomous actions must be observable and permission-controlled.
8. Neuro-inspired mechanisms are hypotheses and engineering tools, not claims of biological equivalence.

## Status

Early architecture phase. The repository currently contains the initial project foundation; implementation will be added incrementally.
